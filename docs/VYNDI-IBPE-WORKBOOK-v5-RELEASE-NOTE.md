# VYNDI IBPE Workbook v5 — Release Note

This branch introduces the controlled VYNDI 36-month Integrated Business Operating Model v5 workbook and its governance note. No application source, migration, deployment, authentication, or environment configuration is changed.

## Included

- `docs/VYNDI_36_Month_Integrated_Business_Operating_Model_v5_Operational_Execution_Governance.xlsx`
- `docs/VYNDI-IBPE-WORKBOOK-v5-GOVERNANCE.md`

## Intended use

The workbook is a planning/reconciliation companion to the governed runtime IBPE. Forecast recommendations remain non-transactional until approved through the relevant operating workflow.
