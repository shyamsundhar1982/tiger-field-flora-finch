# User-reported failure cases

These failures motivated VIBPE Co-Pilot 2.0:

- `Bye` returned a full governed baseline assessment.
- `How to plan for the next 6 months` returned a generic 36-month baseline assessment.
- `20 lakh fund will manage the situation` failed to create and evaluate a ₹20L funding scenario.
- `Next what?` failed to preserve useful conversational/scenario context.

All four behaviors are treated as regressions and are represented in the evaluation corpus.
